# Portfolio framing

## One-sentence description

Built a reproducible Python decision-support system that benchmarks NFL player-availability reporting, evaluates predictive models, and compares stay, investigate, and relocate decisions under uncertainty about a proposed environmental hazard.

## What the project demonstrates

- Data acquisition with provenance, hashes, and reproducible preparation.
- Practical handling of missing reports, repeated observations, changing team abbreviations, and ambiguous public injury fields.
- Temporal validation of count models and calibrated empirical intervals.
- Financial scenario analysis with break-even thresholds and value-of-information logic.
- Clear separation between descriptive association, prediction, and causal inference.

## What it does not claim

The project does not estimate an electromagnetic causal effect, diagnose players, or establish a safe exposure limit. It uses a public weekly-report outcome and treats the environmental hypothesis as an explicit scenario. Facility measurements, clinical records, player workloads, and site-specific bids would be required for a real organizational decision.
